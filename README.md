# tapetris

Tetris where the pieces are rigid bodies. A *Not Tetris 2* for *tape!*.

Tetrominoes fall under gravity as real rigid bodies, can be rotated **freely through 360°** with
the encoder instead of in 90° steps, and they stack physically at whatever angle they land at.
Rows are not deleted - a row that is full enough gets **cut out of the geometry**, and whatever was
resting on it falls.

## Controls

| Control | Action |
| --- | --- |
| **ENCODER** | free rotation of the falling piece |
| **BTN1 / BTN3** | move left / right |
| **BTN2** | drop — hold for soft drop, tap for hard drop |
| **BTN5** | pause |
| **BTN4 (hold)** | exit |
| **BTN2** on the game-over screen | play again |
